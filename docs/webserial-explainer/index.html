The Arduino Side: PulseSensorPlayground Library

Your Arduino reads the sensor and does the math. Here's how:

Step 1: Install the Library

Arduino IDE → Sketch → Include Library → Manage Libraries → Search "PulseSensor" → Install PulseSensor Playground by World Famous Electronics

Step 2: Include & Create

#include <PulseSensorPlayground.h> // Include the library PulseSensorPlayground pulseSensor; // Create instance const int PULSE_PIN = 1; // XIAO ESP32-S3

Step 3: Setup (Initialize)

void setup() { Serial.begin(115200); // USB serial to browser pulseSensor.analogInput(PULSE_PIN); pulseSensor.setThreshold(550); // Sensitivity if (pulseSensor.begin()) { Serial.println("PulseSensor ready"); } }

Step 4: Loop (Read & Send)

void loop() { int signal = pulseSensor.getLatestSample(); int bpm = pulseSensor.getBeatsPerMinute(); int ibi = pulseSensor.getInterBeatIntervalMs(); bool beat = pulseSensor.sawStartOfBeat(); // Send to browser as CSV: Serial.print(signal); Serial.print(","); Serial.print(bpm); Serial.print(","); Serial.print(ibi); Serial.print(","); Serial.println(beat ? 1 : 0); delay(20); // ~50 samples per second }

Step 5: Full Sketch (Copy & Paste)

This complete sketch works on any Arduino-compatible board. Just change the pin number:

Arduino Uno/Nano/Mega: const int PULSE_PIN = A0;
XIAO ESP32-S3: const int PULSE_PIN = 1;
ESP32 DevKit: const int PULSE_PIN = 34; (or any ADC pin)
/* * PulseSensor WebSerial Example * * Reads PulseSensor and sends data over USB Serial * for browser visualization using WebSerial API * * Wiring: * PulseSensor Signal → A0 (or your board's ADC pin) * PulseSensor + → 3.3V (or 5V on classic Arduino) * PulseSensor - → GND * * Install PulseSensorPlayground library: * Arduino IDE → Sketch → Include Library → Manage Libraries * Search "PulseSensor" → Install "PulseSensor Playground" * * By: World Famous Electronics * License: MIT */ #include <PulseSensorPlayground.h> // Create an instance PulseSensorPlayground pulseSensor; // Pin where your sensor is connected // Arduino Uno/Nano/Mega: use A0 // XIAO ESP32-S3: use 1 (GPIO 1) // ESP32 DevKit: use 34 or other ADC pin const int PULSE_PIN = 1; // ← Change for your board void setup() { Serial.begin(115200); delay(1000); // Tell library which pin has the sensor pulseSensor.analogInput(PULSE_PIN); // Optional: adjust sensitivity (higher = less sensitive) // Try 550 as starting point, adjust if needed pulseSensor.setThreshold(550); // Start the library if (pulseSensor.begin()) { Serial.println("PulseSensor ready"); Serial.println("Click 'Connect' above and put finger on sensor"); } else { Serial.println("PulseSensor failed to initialize"); while (1) { Serial.println("ERROR"); delay(1000); } } } void loop() { // Get the raw analog signal (0–4095 on ESP32, 0–1023 on classic Arduino) int signal = pulseSensor.getLatestSample(); // Get calculated BPM (beats per minute) int bpm = pulseSensor.getBeatsPerMinute(); // Get inter-beat interval in milliseconds int ibi = pulseSensor.getInterBeatIntervalMs(); // True if a beat was just detected bool beat = pulseSensor.sawStartOfBeat(); // Send to browser: signal,bpm,ibi,beat Serial.print(signal); Serial.print(","); Serial.print(bpm); Serial.print(","); Serial.print(ibi); Serial.print(","); Serial.println(beat ? 1 : 0); delay(20); // Send ~50x per second }

Key Methods (What the Library Does)

getLatestSample() → raw ADC value (0–4095)
getBeatsPerMinute() → calculated BPM
getInterBeatIntervalMs() → milliseconds between beats
sawStartOfBeat() → true when heartbeat detected
setThreshold(value) → sensitivity (550 = good start)

Why Web Serial?

The Web Serial API (W3C 2017, Google Chrome) gives your browser direct USB access—no software to install, no WiFi needed. Your board does all the math using PulseSensorPlayground, sends only the results, and your browser visualizes them.
