How to get a cleaner waveform

Fingertip

Use the pad of an index or middle finger. Rest it lightly on the sensor and keep your hand relaxed.

Earlobe

Clip gently and keep the cable from tugging. An earlobe can be steadier when hand motion is a problem.

Gentle pressure matters. Squeezing can reduce blood flow and flatten the waveform. If the coach drops back to blue, relax your grip and hold still for a few beats.

Arduino / ESP32 setup

Install PulseSensor Playground from Arduino Library Manager, choose the signal pin for your board, then upload this sketch.

BoardPULSE_PINSensor power
Arduino Uno / Nano / MegaA05V or 3.3V
XIAO ESP32-S313.3V
ESP32 DevKit343.3V
 
/* PulseSensor Web Serial
 * Sends signal,bpm,ibi,beat at 115200 baud.
 * World Famous Electronics LLC · MIT License
 */
#include <PulseSensorPlayground.h>

PulseSensorPlayground pulseSensor;

// Change this for your board. XIAO ESP32-S3 uses GPIO 1.
const int PULSE_PIN = 1;

void setup() {
  Serial.begin(115200);
  delay(1000);
  pulseSensor.analogInput(PULSE_PIN);
  pulseSensor.setThreshold(550);
  pulseSensor.begin();
}

void loop() {
  int signal = pulseSensor.getLatestSample();
  int bpm = pulseSensor.getBeatsPerMinute();
  int ibi = pulseSensor.getInterBeatIntervalMs();
  bool beat = pulseSensor.sawStartOfBeat();

  Serial.print(signal); Serial.print(",");
  Serial.print(bpm);    Serial.print(",");
  Serial.print(ibi);    Serial.print(",");
  Serial.println(beat ? 1 : 0);
  delay(20);
}

What about Signal, Beat, and IBI?

Signal is the raw ADC reading used to draw the waveform. Beat is a one-sample event you can use to flash a light or trigger an animation. IBI is the measured time between accepted beats in milliseconds. Signal Coach keeps these in Technical details because most users need placement guidance and a trustworthy waveform before they need raw timing values.

How Web Serial works

Your board sends signal,bpm,ibi,beat over USB at 115200 baud. The page reads those lines in the browser and draws the waveform. The Signal Coach uses recent waveform range and repeatable beat events to give placement guidance. No samples are sent to PulseSensor.com.
